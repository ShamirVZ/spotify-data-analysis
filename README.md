# Spotify Music Features — Exploratory Data Analysis

Proyecto **académico grupal de Data Science** sobre el análisis exploratorio de características musicales de Spotify.

## Objetivo

Explorar y visualizar distribuciones y relaciones entre variables musicales como popularidad, energía, bailabilidad, acústica, duración y tempo. Este trabajo es de **análisis exploratorio (EDA)**; no se presenta como un modelo de Machine Learning ni como sistema predictivo.

## Herramientas del proyecto

- Python
- Pandas y NumPy para preparación, limpieza y análisis de datos
- Matplotlib y Seaborn para visualización
- Jupyter Notebook

## Dataset y ejecución

El notebook utiliza un archivo denominado `SpotifyFeatures.csv`. **Este CSV no está incluido** en el repositorio inicial.

1. Obtén el dataset utilizado en el trabajo académico, respetando sus condiciones de distribución.
2. Descarga el notebook `spotify_data_science_portfolio.ipynb` y ábrelo en Jupyter o Colab.
3. Coloca `SpotifyFeatures.csv` en el directorio de trabajo correspondiente, o adapta la ruta del archivo en el notebook.
4. Instala las bibliotecas indicadas en `requirements.txt` y ejecuta las celdas en orden.

**Reproducibilidad:** sin el CSV original, el notebook no puede ejecutarse completamente. Los gráficos y estadísticas dependen de la versión concreta de los datos y del entorno.

## Trabajo realizado

El notebook documenta limpieza y exploración de datos, análisis descriptivo, tratamiento de valores atípicos y diferentes visualizaciones. El dataset empleado en el trabajo tiene aproximadamente 232 725 registros y 18 variables.
